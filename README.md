
# Project1: WIKI

An encyclopedia website based on wikipedia.

# Developed using:

> - Django
> - Python
> - HTML
> - CSS
> - Jinja
> - Markdown
> - Boostrap



## Run Locally

Clone the project

```bash
  git clone https://github.com/Alex000127/cs50w-project1.git
```

If you want to use the virtual enviroment
```bash
  pip install virtualenv
```
```bash
  virtualenv venv
```
```bash
  .\venv\Scripts\activate
```


Install dependencies

```bash
  python -m pip install -r requirements.txt
```
Go to the project directory

```bash
  cd cs50w-project1
```

Start the server

```bash
  python manage.py runserver
```
