# HTML: HyperText Markup Language

HTML (HyperText Markup Language) is the standard markup language used to create and design the structure of web pages. It consists of a series of elements, each marked up with tags that define their purpose and appearance on the page.

## Key Features of HTML:

- **Structure Definition:** HTML provides a set of predefined elements that allow developers to structure the content of a web page, including headings, paragraphs, lists, links, images, and more.

- **Semantic Markup:** HTML5 introduced semantic elements that convey meaning to both browsers and developers, improving accessibility, search engine optimization (SEO), and code readability. Examples include `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.

- **Cross-Browser Compatibility:** HTML is supported by all modern web browsers, ensuring consistent rendering and functionality across different platforms and devices.

## HTML5:

HTML5 is the latest major version of HTML, introducing new features and improvements to the language. It includes support for multimedia elements such as `<video>` and `<audio>`, native form validation, canvas for drawing graphics, offline storage with local storage and session storage, and more.

### Key Elements and Tags:

- **Headings:** `<h1>` to `<h6>` tags are used to define headings of different levels, with `<h1>` being the most important and `<h6>` the least.

- **Paragraphs:** The `<p>` tag is used to define paragraphs of text.

- **Lists:** HTML supports ordered lists (`<ol>`) and unordered lists (`<ul>`), with list items marked up using the `<li>` tag.

- **Links:** Hyperlinks are created using the `<a>` tag, with the `href` attribute specifying the URL of the destination.

- **Images:** Images are inserted using the `<img>` tag, with the `src` attribute specifying the image file's URL and the `alt` attribute providing alternative text for accessibility.

By mastering HTML, developers can create well-structured and semantically meaningful web pages that provide a rich and engaging user experience across different devices and platforms.
